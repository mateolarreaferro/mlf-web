A Post-it style app shared with Marielisa: an infinite wall where notes appear on each other's computers in real time. Each day brings an optional prompt in Spanish; notes can be text or voice. A memory system searches past notes by phrase, keyword, or meaning, and as the wall grows, the agent learns from it and suggests new prompts based on recurring themes.

---

## notes

An open version of the wall runs on this site as "sticky notes": the
"interactive demo" button on its card opens mateolarreaferro.com/sticky-notes,
where anyone can leave a text note, signed with a name or anonymous, and see
everyone else's appear. It is in English or Spanish, the visitor's choice,
and opens on a splash with the instructions.
It is a separate wall from Mateo and Marielisa's private one, which stays
private. Visitors can edit and delete only their own notes.
