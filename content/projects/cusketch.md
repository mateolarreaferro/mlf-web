cuSketch is a high-level authoring layer that extends CsoundUnity for building procedural and interactive audio inside Unity. It provides a set of utility classes and modular sketches that simplify common workflows such as mapping Csound channels, triggering score events, driving synthesis with physics data, animating sound sources through spatial trajectories, processing real-time input, and creating audio-reactive behaviors. These components give sound designers and developers a clear and expressive interface for shaping synthesis and control logic without the need for extensive C# boilerplate.
