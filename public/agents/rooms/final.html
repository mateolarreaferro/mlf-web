earlier ideas

Three ways to make the agents hear, build, and maintain a useful world.

01 · Satie Listener

The first step toward acoustic intelligence in a multimodal agent.

who it is for
Satie authors and researchers evaluating spatial audio scenes.
the problem
Satie knows where every source is supposed to be, but an agent cannot yet hear whether the rendered scene actually communicates that location, distance, movement, or event.
what the agent adds
It receives rendered binaural or multichannel audio and predicts source identity, direction, distance, motion, and event timing. Satie compares those predictions with the scene contract and reports localization error, source confusion, audibility, and confidence.
first prototype
Render controlled scenes with one moving source, two overlapping sources, and a source entering from behind. Evaluate localization, event detection, and source separation before attempting a general acoustic model.

02 · Interview-to-Twin

A working version of the AugTwins builder.

who it is for
Someone who wants to create a useful digital twin from a real interview.
the problem
Building a twin currently means assembling memories, a persona, utterance patterns, knowledge files, and audio prompts by hand.
what the agent adds
It conducts a structured interview, extracts memories and speech patterns, asks follow-up questions when information is vague or contradictory, and produces editable AugTwins profile files, memory records, retrieval data, and standard voice prompts.
first prototype
Start with one interview and one agent, such as Pattie. Show every extracted claim with its source passage, confidence, privacy level, and approval state before it enters the twin.

03 · Memory Maintenance Twin

A working version of the AugTwins memory system after the twin exists.

who it is for
People and teams who already have a twin but need its memory to stay trustworthy.
the problem
Memories accumulate duplicates, outdated facts, conflicting versions, missing dates, and privacy mistakes. A twin can sound convincing while its memory quietly degrades.
what the agent adds
It audits the memory hub, groups duplicates, detects conflicts, marks stale facts, asks for resolutions, and proposes a reviewable before-and-after diff. It never silently rewrites the source memory.
first prototype
Run it against an existing AugTwins agent and produce a queue of proposed merges, updates, privacy changes, and unresolved contradictions for human approval.
