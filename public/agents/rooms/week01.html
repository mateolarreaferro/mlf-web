how it works

Qwen 2.5 3B runs locally through Ollama. A Python loop reads the scene’s settings, parses one action, applies it and observes the result. No agent framework.

observe → decide → act → observe again

Actions: inspect, set, undo, done, stop. Completion needs a fresh observation and a separate model check. The limit is 12 turns.

run it

ollama pull qwen2.5:3b
python3 weekly_builds/week01/server.py
